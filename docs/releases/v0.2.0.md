# v0.2.0 — Desktop controls and celestial background

- Globe/Layers/Places sidebar navigation, saved width/layout and pinned or full-height
  Places outline. Ruler/placemark toolbar actions reveal the matching controls.
- Expanded macOS native menus, with the shared GlobeCraft menu on Windows/Linux,
  functional View/Add/Tools/Window/Help actions and localized shortcuts/help.
- DD/DMS/DDM/UTM/UPS/MGRS coordinate input/display, precision and click-to-copy
  readouts. Geographic values and KML remain unrounded. Recognized invalid
  coordinates fail locally; ordinary address search is preserved.
- Searchable, resizable Settings categories; System/Dark/Light themes and separate
  installed UI/map fonts with bundled fallback; mouse navigation gains, inverted
  wheel and a saved startup camera. Cache budgets apply on restart; reset/clear
  actions ask for confirmation.
- Standard controller navigation, hotplugging, per-model profiles, axis/button
  remapping, press-to-bind, deadzones, gain/curves and inversion. Editing/focus
  suspends motion and requires neutral controls before resuming. Tool commands use
  the same app actions as menus.
- NASA diffuse Milky Way backdrop with bounded async loading, correct equatorial
  winding/time transform, realistic daylight fading and explicit cinematic mode.
  Sky-off restores the original path; Earth pixels/tile priorities are preserved.
  NASA/Gaia credits are visible and saved with displayed-frame PNG metadata.

Preferences keep existing paths/formats with tolerant new fields and defaults.
Dark appearance, mouse/keyboard defaults and source geographic values are
preserved. The new celestial background is disabled by default; controllers are
enabled but stay neutral without a connected device. Default imagery targets
remain 256 MiB decoded and 128 MiB managed disk, with best-effort decoded eviction.
The additional shared sky RGB image is 24 MiB outside the imagery budget.

The sky is a 4K SDR derivative (about 2.5 MB compressed), not retained HDR fidelity
or selectable stars. No star catalog, HiPS, Sky/Space Explorer, Studio, flight,
raw HOTAS/HID or SpaceMouse adapter is introduced. Identical controller models may
share a profile. TT uses SOFA's leap table; UT1≈UTC and polar motion is omitted.
Native GPU globe rendering remains experimental and opt-in; release downloads
continue to use the CPU build. Source/rights details are in assets/sky/manifest.json.

Local verification includes locked workspace formatting, Clippy, tests and build,
profiling and CPU-only lint, offline Python packaging/provenance checks, and an
explicit Apple M1 Pro/Metal sky parity run. Physical controllers, complete GUI
interaction/appearance, other GPUs and installed native packages require review
on real devices; successful CI builds do not replace those checks.
